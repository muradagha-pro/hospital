# Arabic Management Presentation Generator

This folder contains a script that builds an Arabic PowerPoint presentation for hospital management.

## Files
- `generate_presentation.py`: creates `Hospital_Management_Presentation_AR.pptx` in the project root.
- `requirements.txt`: Python dependencies for generation.

## Quick Run
```bash
cd /Users/baselmurad.agha/Downloads/hos-main
python3 -m venv .venv-ppt
source .venv-ppt/bin/activate
python3 -m pip install -r presentation/requirements.txt
python3 presentation/generate_presentation.py
```

## Output
- `/Users/baselmurad.agha/Downloads/hos-main/Hospital_Management_Presentation_AR.pptx`
